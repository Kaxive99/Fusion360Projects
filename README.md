# Fusion 360 Projects

Personal collection of CAD models and 3D enclosures designed for electronics.

## 📁 Projects:
* **`esp32-ecu-enclosure/`** – Custom enclosure for ESP32 DevKit V1 and 0.96" OLED display.
  * **Dimensions:** 55 x 35 x 25 mm
  * **Standoffs:** 20 mm
  * **Cutouts:** OLED (24 x 13 mm), USB (20 x 5 mm), Pins (38 x 3.7 mm)

## 🛠️ File Formats:
* `.stl` / `.3mf` – Ready for 3D printing
* `.step` – Source CAD files for editing
